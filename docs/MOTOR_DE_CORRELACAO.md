# Motor de Correlação de Identidade

O ICE é um módulo independente para uma identidade verificada. Ele conserva proveniência, fonte original/intermediária, data, independência e restrições de evidência.

Fluxo: coleta → normalização → deduplicação → proveniência → ancoragem → correlação → conflitos → classificação → revisão → relatório.

Regras: nomes e apelidos semelhantes não confirmam identidade; republicações de um incidente não criam múltiplas fontes; evidência sem origem é inferior; conflitos reduzem confiança; dados sensíveis não têm associação automática por texto; o titular pode confirmar, rejeitar ou corrigir cada afirmação.
